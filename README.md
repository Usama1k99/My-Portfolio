# Syed Usama — Portfolio

Personal portfolio and capability showcase for **Syed Usama**, ServiceNow Developer at Cynosure Technologies and Software Engineer.

## Tech Stack
- **Framework**: React 18 + Vite + TypeScript
- **Styling**: Tailwind CSS
- **Icons**: Lucide React (SVG, zero emojis)
- **Visuals**: Native HTML5 Canvas 2D interactive kinetic particles
- **Deployment**: Vercel (Free Tier ready)

## Quick Start
```bash
# Install dependencies
npm install

# Run locally
npm run dev

# Build for production
npm run build

# Lint check
npm run lint
```

## Deployment
Pre-configured for one-click deployment on **Vercel** with optimized SPA rewrites and static asset caching defined in `vercel.json`.
